# Lady & Lord - Shopping Cidade dos Lagos (Guarapuava)

Protótipo de Landing Page de Alta Conversão e Triagem Inteligente para a unidade **Lady & Lord Shopping Cidade dos Lagos** em Guarapuava - PR.

---

## 💎 Proposta de Valor para a Franquia

1. **Pré-Agendamento Inteligente via WhatsApp**:
   - O cliente escolhe na página o serviço (Espaço Lady ou Espaço Lord), o turno (manhã, tarde, noite) e o dia de preferência.
   - O botão gera uma mensagem 100% pronta e estruturada no WhatsApp da recepção.
   - A equipe da recepção ganha agilidade para consultar a grade no sistema interno e confirmar o agendamento em segundos, eliminando o "ping-pong" manual de mensagens.

2. **Destaque do Espaço Lord (Barbearia Executiva)**:
   - Resgate do posicionamento masculino tradicional da rede (corte executivo, barboterapia com toalha quente, chopp/café cortesia).

3. **Conveniência de Shopping**:
   - Foco nos diferenciais do Shopping Cidade dos Lagos: estacionamento coberto, segurança, facilidade de acesso e funcionamento estendido até as 22h.

---

## 🛠️ Stack Tecnológica

- **React 19**
- **Vite 8**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Lucide Icons**
- **Design System**: Paleta Luxury Noir & Champagne Gold com variáveis CSS (`var(--color-...)`).
